Ikon HTML index HTML Karena kode di Apps Script milikmu masih bergantung penuh pada API internal Google (google.script.run dan HtmlService), memindahkan kode mentah secara langsung ke Vercel akan membuatnya error. Namun, ada solusi yang jauh lebih baik dan selaras dengan Kode.gs milikmu. Pada file Kode.gs, kamu sudah mengaktifkan setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL). Ini artinya, kamu sudah "membuka kunci" agar aplikasi tersebut bisa di-embed di domain luar seperti Vercel. File HTML di atas menggunakan metode Dynamic Iframe Routing. Cara kerjanya: File HTML ini di-hosting di GitHub & Vercel. Ketika dikunjungi, file ini akan memuat Web App Google Apps Script kamu secara full screen, jadi terlihat persis seperti website asli (URL tidak terlihat seperti script.google.com). Jika kamu mengetik domain-vercelmu.vercel.app/?page=admin, file HTML otomatis menangkap parameter ?page=admin dan mengirimkannya ke Apps Script untuk membuka Panel Admin! Langkah Sinkronisasi ke Vercel: Deploy Apps Script: Di Google Apps Script, klik Deploy > New Deployment. Pilih tipe "Web app", atur akses "Anyone", lalu salin URL Web App yang panjang (berakhiran /exec). Edit HTML di Github: Buat repositori baru di GitHub. Upload file index.html yang saya buat di atas. Edit baris ke-30 pada index.html dan ganti tulisan GANTI_DENGAN_ID_DEPLOY_KAMU dengan URL Web App milikmu. Deploy di Vercel: Masuk ke dashboard Vercel, pilih Add New > Project. Impor repositori GitHub yang baru kamu buat tadi. Klik Deploy. Karena sistemnya bersifat Embed, setiap kali kamu mengedit atau memperbarui kode Index.html, Admin.html, Cek.html, atau Kode.gs langsung di Google Apps Script (lalu di-Deploy ulang sebagai versi baru), perubahannya akan otomatis tersinkronisasi di Vercel tanpa perlu melakukan commit atau push apa pun di GitHub lagi.
